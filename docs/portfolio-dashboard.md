# Генератор кредитного портфеля (C++17)

## Сборка PowerShell
```powershell
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
.\build\Release\portfolio.exe --profile short --out result-short
Start-Process .\result-short\report.html
```
Для одноконфигурационного генератора executable в build/ без Release/.

## Профили и повторный запуск
```powershell
.\build\Release\portfolio.exe --profile floating --save-config my-profile.ini --out run-1
# Отредактируйте my-profile.ini для своих настроек.
.\build\Release\portfolio.exe --config my-profile.ini --out run-2
.\build\Release\portfolio.exe --config run-2/config.ini --out replay
.\build\Release\portfolio.exe --config my-profile.ini --seed 43 --out new-run
```
short — короткие кредиты; long — длинные сделки; floating — плавающие ставки. Можно редактировать копии profiles/*.ini. Профиль и конфиг выбираются альтернативно, --seed перекрывает значение из конфига. Папка вывода должна быть пустой или отсутствовать; существующие результаты не перезаписываются.

## Единицы и настройки
count — количество сделок (1..1000000), не общий денежный объём. min_amount/max_amount — копейки (1..1e12). min_term/max_term — месяцы (1..1200). ann/simple/rgm — доли по количеству в сотых процента, сумма 10000. floating — доля плавающих ставок в тех же единицах. min_rate/max_rate — фиксированная ставка в базисных пунктах (1200 = 12%). min_spread/max_spread — надбавка в базисных пунктах (100 = 1 п.п.). seed — 0..4294967295. version — версия алгоритма 1.0.0. Неуказанные поля получают тестовые значения по умолчанию; полный конфиг сохраняется с результатами.

## Результаты и просмотр
portfolio.csv — все сделки; config.ini — полный конфиг; summary.txt — задано/получилось; report.html — автономный интерактивный отчёт без сервера. Нажатие столбца фильтрует сделки, строка открывает параметры. Есть фильтры, поиск по ID, пагинация и экспорт выборки. Показаны заданные и фактические доли типов платежей, ставок, интервалов сумм и сроков. Генерация/редактирование профилей — через CLI/INI, не в браузере. HTML содержит JavaScript только для просмотра; генератор написан на C++.

## Воспроизводимость
mt19937 с явным seed; два последовательных выхода образуют uint64 (сначала старшие биты). Rejection sampling для диапазонов, явный Fisher-Yates для перемешивания. Квоты по методу наибольших остатков; ничьи: ANN/SIMPLE/RGM и FIXED/FLOATING. Сначала перемешиваются типы платежей, затем ставки, затем по сделке генерируются сумма, срок, ставка/надбавка. Целочисленная генерация, без std::uniform_distribution и std::shuffle. Одинаковые настройки и версия алгоритма дают одинаковые сделки. CSV: стабильный порядок, LF.

## Ограничения
Суммы/сроки равномерные, тестовые; признаки независимы за исключением квот. Реальные распределения ожидаются позже. ANN/SIMPLE/RGM — только метки, без расчёта платежей. NPV, дисконтирование и экономкапитал не считаются. Плавающая ставка — TEST_INDEX плюс надбавка, без прогноза индекса и дат пересмотра. Это CLI с HTML-отчётом, не нативный GUI. Большой HTML тяжёлый; для крупных портфелей используйте CSV. Проверяются диапазоны, доли, seed, повторяемость, квоты, границы, сохранение/чтение и экспорт. Браузерные сценарии требуют отдельной ручной проверки.


## Запуск после клонирования

Сборка:
```powershell
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

После сборки запустите START_APP.cmd.
Первый запуск автоматически создаёт reports/builtin-demo.html
из синтетических CSV в tests/fixtures/cf/.

Свои CSV загружаются через интерфейс и не нужны для сборки.
Факторный анализ — явно обозначенный демонстрационный пример.
Свои профили хранятся в браузере; перенос настроек через INI.
Приложение предназначено для локального запуска под Windows.
