## Основные результаты

Дата оценки — 31.08.2022, остаток долга — 3 646 037,89 RUB, кредитная ставка — 7,5%, дисконтная ставка — 7,5%, ACT/365F, 334 платежа до 15.06.2050.

| График | Всего процентов, RUB | PV будущих платежей, RUB | Конечный долг, RUB |
|---|---:|---:|---:|
| ANN | 5 039 033,17 | 3 646 037,92 | 0,00 |
| SIMPLE | 7 604 236,54 | 3 646 037,88 | 0,00 |
| RGM | 3 812 984,12 | 3 646 037,90 | 0,00 |

PV почти равна исходному долгу из-за равенства ставок и последовательного дисконтирования. Копеечные отклонения связаны с округлением. Дисконтная ставка — учебное допущение; рыночная кривая не используется. Это стоимость оставшихся платежей, а не Economic Capital или полный NPV от выдачи кредита.

## Повторить расчёт

Распакуйте архив. Из его корня выполните в Python 3.12 или новее:

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m sprint1.run
```

Для другого набора условий скопируйте `contracts/request.example.json`, измените параметры и выполните:

```powershell
python -m sprint1.run --input my_request.json --output outputs/my_case --skip-reference
```

`--skip-reference` отключает только сравнение с исходной сделкой; внутренние проверки сохраняются. Повторный запуск обновляет результаты в выбранной выходной папке.

## Excel

Жёлтые ячейки C6:C8 листа «Параметры» позволяют менять долг, кредитную и дисконтную ставки. Календарь и число платежей фиксированы для исходной сделки. Новый календарь задаётся через JSON и повторную сборку Excel.

Скрипты сборки используют bundled Node.js и `@oai/artifact-tool` среды Codex. Если зависимости ещё не подключены, в PowerShell:

```powershell
$taskDeps = "$env:USERPROFILE/.cache/codex-runtimes/codex-primary-runtime/dependencies"
New-Item -ItemType Directory -Path .runtime -Force | Out-Null
New-Item -ItemType Junction -Path .runtime/node_modules -Target "$taskDeps/node/node_modules" | Out-Null
& "$taskDeps/node/bin/node.exe" scripts/build_workbook.mjs
```

Для другого расчёта добавьте путь к выходной папке аргументом скрипта.
