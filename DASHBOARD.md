# Локальное приложение кредитного портфеля

## Сборка и запуск (Windows)

```powershell
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
.\START_APP.cmd
```

Приложение открывается на http://127.0.0.1:8765. Для сборки нужны CMake и компилятор C++17. Для Python-тестов нужен Python; браузерный тест может требовать дополнительные зависимости.

## Возможности

- Генерация повторяемого портфеля по seed и INI.
- Настройка параметров, генерация и сохранение собственных профилей в браузере.
- Договорные графики ANN, SIMPLE и RGM на C++.
- Оценка PV портфеля и месячные денежные потоки.
- Расчётное факторное разложение в отчёте генератора.
- Импорт пары deal_summary.csv/cashflows.csv с проверкой согласованности.

Собственные профили хранятся в localStorage браузера; для переноса скачайте INI.

## Где расчёт, а где демонстрация

Расчётный анализ доступен после генерации в разделе отчёта «Факторный анализ изменения стоимости». factor_analysis.csv содержит его результаты.

Отдельная вкладка «Факторный анализ · ДЕМО» содержит заранее заданные числа. Они не связаны ни с импортированными CF, ни с расчётным анализом генератора.

Импорт CF проверяет даты, типы, числа, суммы, flow_count и балансовое равенство. Допуск сверки сумм 0,005 RUB. current_interest не прибавляется к CF. Импорт не запускает оценку PV или факторный анализ этих файлов. CSV поддерживает кавычки и запятые, но не многострочные поля.

При первом запуске встроенный CF-отчёт создаётся из синтетического tests/fixtures/cf. Локальные банковские выгрузки не нужны. Интеграционный тест закреплён за этой fixture: одна сделка, две строки потоков, суммарный платёж 26037,32 RUB за 2022-09-22.
