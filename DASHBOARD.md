# Dashboard CF + факторный ДЕМО
Сборка: cmake -S . -B build; cmake --build build --config Release
Тесты: ctest --test-dir build -C Release --output-on-failure
Создание отчёта: .\build\Release\dashboard.exe data/input reports/dashboard.html
Открытие: Start-Process .\reports\dashboard.html
Исходные CSV не меняются. При повторном экспорте задайте новое имя HTML.
CF проверяются по instrument_id: типы, даты, числа, суммы с допуском 0,005, число строк, начальное тело минус погашение равно остатку. Контроль 1 / 2022-09-22 = 26037,32. Тест интеграции закреплён за текущей выгрузкой 44 сделки/3965 строк; для другого датасета измените fixture-тест. current_interest не прибавляется к CF. Суммирование до форматирования в 2 знака. Поддерживаются CSV-поля с кавычками и запятыми, но не многострочные поля.
Факторный раздел — явно подписанные вручную подготовленные данные для защиты. Не связан с CF и не рассчитывает NPV. Доступны три пары месяцев август–сентябрь–октябрь 2026. Взаимодействия учитываются отдельно один раз. Выдуманные значения не выдаются за результат модели.
Генератор сохранён отдельно, ссылка ведёт к demo/report.html. Формы редактирования/запуска генератора в браузере пока нет. В браузере используются JS для отображения, C++ для импорта и сверки. Интерактивность нужно проверить вручную.
