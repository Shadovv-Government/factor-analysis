C++ · Генерация · Денежные потоки · Факторный анализ
Локальное приложение
Готово к работе. Расчёты выполняет C++ на вашем компьютере.

Настройка портфеля

Свои профили хранятся в этом браузере. Для переноса на другой компьютер скачайте INI. Версия генератора: 1.0.0.

Распределения сумм, сроков и ставок пока равномерные. Доли считаются по количеству сделок. Плавающая ставка: TEST_INDEX + надбавка. Размер портфеля — число сделок, не общая сумма.

Результат генерации

Столбцы диаграмм открывают соответствующие сделки; строка сделки — её параметры. CSV и полный конфиг доступны внутри отчёта.

Импорт платежей первой команды

Связь по instrument_id. Проверяются типы потоков, даты, суммы, количество строк и остатки. NPV базы/стресса не рассчитывается. Исходные файлы не перезаписываются.

Факторный анализ ДЕМО

Вклады и NPV заданы заранее для защиты, не рассчитаны на CF. Выберите два периода и нажмите на фактор для подробностей.
